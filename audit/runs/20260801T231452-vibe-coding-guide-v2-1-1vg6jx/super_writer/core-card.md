# Core Card

- Core Statement：给 AI 编程立规矩，靠"请 AI 自觉"没用；v2.0 用体检脚本 + 强制护栏，把规矩变成了 AI 绕不过去的机制。而这一天的开发过程本身，证明"有人复核"比"AI 自觉"可靠得多；且一个安全工具的可信度，来自它肯承认自己的宣传哪里不成立。
- Reader Change：读者对"AI 护栏"的认知从"一份规矩清单"变为"可执行机制 + 测试覆盖 + 明示失效场景"；对"测试全绿"和"大数字检查报告"产生警惕；认识到宣传语需要被审查。
- Core Tension：第一版文章里说好的"安全气囊"，v1.0 其实只是一张贴在方向盘上的纸条；最危险的洞（私钥硬拦规则死掉）被 32 条全绿的测试完美掩盖；而 README 顶部那句"红线自动拦截"，从 v1.0 起就比代码领先两个版本。
- Value Carrier：主动认账第一版吹牛 + 四个自曝故事（32 条全绿 / AI 改测试题 / 三次停下来问 / AI 用更弱证据推翻自己的正确怀疑）+ 主动缩小宣传（install.sh 输出写明不保证生效）+ 277 告警 261 假。
- Scope：只讲安全与确认机制，不讲代码质量；只讲 Windows + Claude Code 实测，不吹全平台。
- Result：读者看完相信"护栏要真能拦，不能靠自觉；宣传要经得起审查"，并愿意去 GitHub 安装 / star / 分享翻车经历。
