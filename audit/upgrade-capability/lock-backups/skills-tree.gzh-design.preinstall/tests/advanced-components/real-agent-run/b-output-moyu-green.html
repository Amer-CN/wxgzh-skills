拆分 FAQ

Q: 拆分后性能下降怎么办？

A: 先用 API 网关的批量聚合减少调用数，再逐步优化热点路径。

Q: 数据库怎么拆？

A: 按业务域拆，先做读写分离，再做垂直拆表。
