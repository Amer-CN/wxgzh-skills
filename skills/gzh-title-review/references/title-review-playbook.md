# 标题复盘手册（title-review-playbook）

## 输入

- 正文（final_article.md 或发布版正文）
- 发布数据：打开率、转发、完读、发布时段、同题竞品表现
- 缺失数据项必须如实标注「无数据」，不得用感觉补位

## 第一步：重跑标题诊断（对照 title-playbook）

1. 文章唯一主判断是什么（一句话）。
2. 标题承诺了什么（点击欲望来自哪里）。
3. 正文是否兑现承诺：数字/对象/动作逐项核对（无据即标）。
4. 风险标记：标题党 / 堆砌 / 无据 / 时效，命中即记。

## 第二步：对照四分类归因

| 归因 | 判据 | 证据要求 |
|---|---|---|
| 标题因素 | 承诺与供给错位；或风险标记命中且与表现相关 | 标题原文 + 正文对照摘录 |
| 选题时机 | 热点窗口/同题扎堆/读者群不在场 | 时间线或同题数据 |
| 账号分发 | 报道者推送时段/频次/粉丝池错位 | 推送记录或粉丝数据 |
| 无法判断 | 无数据或样本 < 可判阈值 | — |

规则：只落一类（+ 可混「无法判断」）；证据不足一律「无法判断」。

## 第三步：输出结构

```markdown
## 复盘结论
- 归因：<一类>（可验证/待验证）
- 证据：<数据或对照摘录>
- 主承诺与供给：<一句话对照结论>
## 下一次动作
- <唯一一个最重要的动作>
## 可复用规则（若有）
- <一条规则 + 适用条件>
```

## 纪律

- 复盘是发布后动作，不改变已发布内容。
- 每条结论标「可验证/待验证」：可验证=有数据或可复测；待验证=假设。
- 不因单篇差表现否定方法论；三次同类归因才值得改流程。
- 保留作者语气：建议只动承诺与供给的错配，不动作者风格。
