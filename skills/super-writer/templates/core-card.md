# Core Card

（canonical 格式（77B/OBS-311）：`字段: 内容` 同行一行式；字段与内容之间用半角冒号或全角冒号，内容非空。两校验器（validate_single_product 与 full-mode）同判，不再接受 `**字段**` 独占形态。）

Core Statement: 一句话说出文章最核心的判断（读者看完要记住的那句）。

Reader Change: 阅读前读者认为/不知道什么 —— 阅读后变成什么。

Core Tension: 核心张力（性能越强 vs 风险越大 这类对立，一句话）。

Value Carrier: 靠什么让判断可感（关键数据/机制/出处，一句话）。

Scope: 适用于什么、不适用于什么。

Result: holds / 或者对该核心的最终裁决（一句话）。
