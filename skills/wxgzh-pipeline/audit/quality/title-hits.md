# 标题 hits 台账（title-hits）

> 档 77AA：自建标题命中台账。只沉淀本号真实表现数据，不抄别家榜单
> （参照 Weikezi-AI/title-craft「只收小号爆款防大 V 基数污染」的精神——
> 我们不抄别家，只沉淀自己）。发文后把本篇选定标题追入台账；表现数据
> 出来后回填并标验证状态。轻义务：回填不阻断发文流水线。

## schema

| 列 | 说明 |
|---|---|
| 日期 | 发文日期（YYYY-MM-DD） |
| RUN_ID | 发文 RUN 短 ID |
| 标题 | 选定标题，逐字与 article.md H1 一致 |
| 组 | 生成组：稳健准确 / 网感点击 / 专业权威 / 长期价值 |
| 五维分 | 总分 + 五项（点击欲望/事实匹配/人群匹配/差异化/长期价值） |
| 风险标记 | 标题党 / 堆砌 / 无据 / 时效，或「无」 |
| 表现回填位 | 阅读 / 分享 / 分享率（拿到真实数据后填入） |
| 验证状态 | 三态：待回填 / 已验证 / 已证伪 |

## 验证状态（三态）

- **待回填**：尚未拿到真实表现数据。
- **已验证**：表现回填后与选题预期同向（如网感组候选拿到点击/分享实证）。
- **已证伪**：表现回填后不达预期——对应范式/关键词降权，回炉 `title-patterns.md`；实证优先，不删行、不改历史行。

## 纪律

- **只追加不删改**：新行向下追加；旧行有误用新行更正，历史行不动。
- **只收本号真实数据**：表现数字只来自本号公众号后台，禁止估算、禁止引用他号数据。
- **回填必须闭环**：拿到数据后必须把「待回填」改判为「已验证」或「已证伪」，不许永久挂着待回填（在追加新行时一并处理，不改历史行——判级以最新一行备注为准）。
