为什么需要高级组件

传统排版只能处理标题、正文和图片。当文章需要提示风险、对照代码、展示对话时，普通 Markdown 语法力不从心。高级组件解决了这个问题。

WARNING

组件不是越多越好

默认每篇文章 3-6 个重点高级组件；短资讯通常 0-2 个。全塞只在验收时使用。
